# MyPortfolio - Design System Master

## Overview
Generated by UI/UX Pro Max skill for portfolio blog cards and content presentation.

## Pattern: Scroll-Triggered Storytelling
- Narrative-driven design with clear chapter sections
- Progress indicator for user guidance
- Mobile-friendly animations (simplified under reduced motion)
- CTA placement at chapter ends and final climax
- DOM reading order maintained for accessibility

### Sections
1. Intro hook
2. Chapter 1 (problem)
3. Chapter 2 (journey)
4. Chapter 3 (solution)
5. Climax CTA

## Style: Swiss Modernism 2.0
- **Mode:** Light and Dark supported
- **Keywords:** Grid system, Helvetica, modular, asymmetric, international style, rational, clean, mathematical spacing
- **Best For:** Corporate sites, architecture, editorial, SaaS, museums, professional services, documentation
- **Performance:** Low cost, no special drivers
- **Accessibility:** Low risk, requires contrast 4.5:1, keyboard nav, visible focus, reduced motion

## Typography
### Font Pairing: Libre Bodoni / Public Sans
- **Mood:** Magazine, editorial, publishing, refined, journalism, print
- **Best For:** Magazines, online publications, editorial content, journalism
- **Google Fonts Import:**
```css
@import url('https://fonts.googleapis.com/css2?family=Libre+Bodoni:wght@400;500;600;700&family=Public+Sans:wght@300;400;500;600;700&display=swap');
```

### Typography Scale
- Base: 16px
- Line-height: 1.5
- Heading hierarchy: h1 (2.5rem), h2 (2rem), h3 (1.5rem), h4 (1.25rem), h5 (1.125rem), h6 (1rem)

## Layout System
- **Grid:** display: grid
- **Template:** grid-template-columns: repeat(12 1fr)
- **Gap:** 1rem
- **Spacing:** Mathematical ratios (golden ratio, fibonacci sequence)
- **Breakpoints:**
  - Mobile: 375px
  - Tablet: 768px
  - Desktop: 1024px
  - Large: 1440px

## Effects & Interactions
- **Transitions:** 150-300ms smooth duration
- **Hover States:** With smooth transitions
- **Focus States:** Visible for keyboard navigation
- **Reduced Motion:** Respects prefers-reduced-motion

## Pre-Delivery Checklist
- [ ] No emojis as icons (use SVG: Heroicons/Lucide)
- [ ] cursor-pointer on all clickable elements
- [ ] Hover states with smooth transitions (150-300ms)
- [ ] Light mode: text contrast 4.5:1 minimum
- [ ] Focus states visible for keyboard nav
- [ ] prefers-reduced-motion respected
- [ ] Responsive: 375px, 768px, 1024px, 1440px

## Implementation Notes
- Avoid poor typography and slow loading
- Use mathematical spacing ratios
- Maintain clear visual hierarchy
- Ensure accessibility compliance
- Test on all target breakpoints
